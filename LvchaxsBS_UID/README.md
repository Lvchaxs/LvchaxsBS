# LvchaxsBS_UID

**一个纯本地的原神账号管理工具 —— 只做账号的「添加 / 保存 / 查看」。**

> 本项目由 [LvchaxsBS](https://github.com/Lvchaxs/LvchaxsBS) 精简而来：
> 保留了原有的界面布局与交互逻辑，**移除了全部截图 / 图像识别 / 模板匹配 / 自动登录相关代码**，
> 只留下账号管理本身。

---

## 功能

- **账号管理**：添加、编辑、删除账号，记录 UID、冒险等级、昵称、账号（手机号/邮箱）、密码。
- **分组管理**：创建分组分类管理账号，支持批量移入、移出，分组内独立标记。
- **标记 / 置顶**：分组内标记账号（跑完每日任务打一个标记），主列表可置顶常用账号。
- **搜索 / 排序**：按 UID、昵称、账号搜索；UID、等级、昵称、账号多列正序倒序排序。
- **查看与复制**：一键复制 UID / 账号 / 密码，密码默认打码，可切换显示。
- **完全本地**：无任何联网行为，数据只保存在本机。

## 数据存储

所有本地数据统一放在**程序目录下的 `Config` 文件夹**里，程序根目录只留可执行文件本身：

```
<程序目录>/
  LvchaxsBS_UID.exe
  Config/
    accounts.enc.json          # 账号数据（含密文账号 / 密码）
    groups.json                # 分组数据
    pinned_orders.json         # 置顶顺序
    mark_after_login_preference.json
    login_checkbox_settings.json
```

账号数据即是 `Config/accounts.enc.json`：

- 账号与密码在写入前会经过一层**简单混淆**（固定密钥异或 + Base64，带 `enc:` 前缀），
  目的是让你直接打开数据文件时**看不懂里面的内容**；
- 这是为了「防误看」、「防随手偷窥」级别的遮蔽，**不是密码学意义上的安全加密**，
  请勿用它保护真正的高价值机密；
- 程序不做任何网络上传，也不依赖任何第三方服务。

首次启动时会自动把旧版本散落在根目录的数据文件搬进 `Config`（只搬一次，不覆盖已有数据）。
帮助窗口的「不再提示」设置不在这里，位于 `%LocalAppData%\LvchaxsBS_UID\`。

> 关于登录：界面上的「登录」按钮与「确认登录」窗口**仅保留界面**，
> 本版本不含截图识别与自动登录，点「确认登录」只会提示本版本不提供登录功能。

## 构建

需要 **.NET 8 SDK** 与 Windows 环境（WPF）。

```bash
git clone https://github.com/Lvchaxs/LvchaxsBS_UID.git
cd LvchaxsBS_UID
dotnet build -c Release
```

生成结果位于 `bin/Release/net8.0-windows/LvchaxsBS_UID.exe`。
本项目仅面向 Windows（`net8.0-windows` / WPF），无法在 Linux 或 macOS 上运行。

## 目录结构

```
LvchaxsBS_UID.csproj      # 项目文件（无任何 NuGet 依赖）
App.xaml / App.xaml.cs    # 应用入口与全局样式
Models/                   # Account、AccountGroup 数据模型
Services/
  DataServices/           # 账号、分组、排序的读写服务（JSON）
  EncryptionServices/     # 轻量级本地数据混淆
Utils/                    # 剪贴板、文件、Toast / 模态框 / 视图状态
Converters/               # XAML 值转换器
Views/                    # 主窗口与各编辑窗口
```

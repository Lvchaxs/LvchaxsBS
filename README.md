# LvchaxsBS

面向 **《原神》国服（YuanShen）** 与 **《原神》国际服（Genshin Impact）** 的 Windows 桌面辅助工具，
基于 **.NET 8 + WPF** 开发。

项目整体思路是「新 UI + 旧引擎」：界面层重做成自定义控件、主题动效与更顺手的交互，
功能层沿用一套相对成熟的逻辑内核。

## 构建

需要 **.NET 8 SDK** 与 Windows 环境。

```bash
git clone https://github.com/Lvchaxs/LvchaxsBS.git
cd LvchaxsBS
dotnet build LvchaxsBS.sln -c Release
```

生成结果位于 `LvchaxsBS/bin/Release/net8.0-windows/`。
本项目仅面向 Windows（`net8.0-windows` / WPF / Win32 窗口与截图相关 API），无法在 Linux 或 macOS 上运行。
